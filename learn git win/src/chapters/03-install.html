Installing Git on Windows

Git for Windows is one free download. There are two ways to install it: a single command, or the classic installer with a dozen screens. Both give you the same Git; this stop covers both.

Step 0: maybe it is already there

Some PCs already have Git (it arrives with certain developer tools). Open a terminal and ask:

git --version

If you see a version number like below, skip to the next stop. If you get "not recognized", install it.

git version 2.51.0.windows.1

Step 1: install

winget is Windows' own app installer for the terminal. Run this in a normal PowerShell window:

winget install --id Git.Git -e --source winget
  • The first time, winget may ask you to accept its source agreements. Type Y and press Enter.
  • Windows asks "Do you want to allow this app to make changes to your device?" Click Yes.
  • Wait for "Successfully installed".

Win 11 winget is built in.

Win 10 winget comes with the "App Installer" app. If PowerShell says winget is not recognized, open the Microsoft Store, search for App Installer, update it, and try again. Or use Option B.

Note

winget installs with the installer's default answers. Two of those defaults are unfriendly (the Vim editor, and "master" as the first branch name). The next stop fixes both with one command each, so no harm done.

  1. Go to git-scm.com, click Downloads, then Windows. Download the "64-bit Git for Windows Setup". (Any PC from the last ten years is 64-bit.)
  2. Open the downloaded file. Windows asks whether the app may make changes: click Yes.
  3. Click through the screens. The walkthrough below shows every one of them and what to pick. Almost everything stays on the default; one screen really matters (the editor).

The installer, screen by screen

Click Next in the mock-up (or the dots) to step through. The green outline marks the recommended choice; the right-hand panel explains it in plain words.

Step 2: open a new terminal and check

Careful

A terminal only learns about programs that existed when it started. Close every terminal window (and VS Code, if it was open) and open a fresh one. This single step fixes most "Git is not recognized" problems.

git --version
git version 2.51.0.windows.1

Your number may be higher. Any 2.x version is fine for everything in this guide.

What you got

  • git itself, usable from PowerShell, Command Prompt and any editor.
  • Git Bash: a Linux-style terminal. Find it in the Start menu. Useful when a tutorial uses Linux commands; optional.
  • Git Credential Manager: the helper that signs you in to GitHub later with one browser click.
  • Git GUI and gitk: two old-school graphical tools. You can ignore them.

Nice to have (optional)

Visual Studio Code

A free editor with excellent Git support built in. It shows changed lines, conflict buttons and a Source Control panel.

winget install --id Microsoft.VisualStudioCode -e

Windows Terminal

Tabs, proper copy and paste, better fonts. Built into Windows 11, a free add-on for Windows 10.

winget install --id Microsoft.WindowsTerminal -e

PowerShell 7

The newer PowerShell. Windows ships version 5.1, which works fine for this guide; 7 fixes a few old quirks you will meet in Stop 16.

winget install --id Microsoft.PowerShell -e

Troubleshooting

ProblemFix
"git is not recognized" after installingClose all terminals and editors and open a new one. Still broken: restart the PC. Still broken: run the installer again and keep the recommended PATH option ("Git from the command line and also from 3rd-party software").
"winget is not recognized"Update "App Installer" from the Microsoft Store, or use the installer from git-scm.com.
Installer blocked on a work or school PCYou probably lack admin rights. Ask IT; many companies offer Git through a software portal.
Want to update Git laterwinget upgrade --id Git.Git, or git update-git-for-windows, or just run a newer installer.

Which installer screen matters most for beginners?

  • Select Destination Location
  • Choosing the default editor
  • Select Start Menu Folder

The default editor is Vim, which traps beginners. Pick VS Code or Notepad. (Fixable later with one command.)

Git is installed but the terminal says "git is not recognized". Most likely cause?

  • The terminal was opened before Git was installed
  • You need to type Git with a capital G
  • You need a GitHub account first

Old terminal windows do not see newly installed programs. Open a new one.
