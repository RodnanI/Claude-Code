The terminal, minus the fear

The terminal is a window where you type instructions instead of clicking. It looks old-fashioned, but it only does what you already do with the mouse: open folders, make files, run programs. Fifteen minutes here makes every other stop easier.

Terminal, shell, PowerShell... what are all these words?

  • The terminal is the window itself.
  • The shell is the program inside that window which reads your commands and runs them.
  • PowerShell is the shell built into Windows 10 and 11. This guide uses it everywhere.
  • Command Prompt (cmd) is the older Windows shell. It works with Git too, but its commands differ.
  • Git Bash arrives with Git (next stop). It is a Linux-style shell. Handy for following Linux tutorials, not required here.

On Win 11 the window app is called Windows Terminal and it opens PowerShell by default. It has tabs, so you can have several terminals side by side.

On Win 10 PowerShell opens in a plain blue or black console window. That is fine, but installing Windows Terminal (free, from the Microsoft Store) gives you tabs, better copy and paste and nicer fonts. Recommended, not required.

Open a terminal

From anywhere: right-click the Start button (or press Win + X) and pick Terminal. It starts in your home folder, C:\Users\yourname.

Right inside a folder (the most useful way): open the folder in File Explorer, right-click an empty spot and choose Open in Terminal. The terminal starts in that exact folder.

Windows 10: Shift + right-click the empty space inside a folder.

Trick that works on both: click File Explorer's address bar (where the folder path is shown), type powershell and press Enter. PowerShell opens in that folder.

Tip

Do not pick "Run as administrator" for everyday Git work. A normal terminal is correct. Admin rights are only for the rare command that says it needs them.

Reading the prompt

When the terminal is ready for you, it shows a prompt:

The middle part is the current folder: the folder the terminal is "standing in". Commands act on it. Git commands in particular act on the repository you are standing in, so "where am I?" is the first thing to check whenever something behaves oddly.

Paths: addresses for files

A path is a file's address. C:\Users\you\Documents\notes.txt means: drive C, folder Users, folder you, folder Documents, file notes.txt. Folders are separated by backslashes. A few shortcuts:

Keys that save your sanity

  • Tab completes file and folder names. Type the first letters, press Tab, press it again to cycle. PowerShell writes .\ in front of the name; that just means "in this folder".
  • ↑ brings back the previous command. Press again to go further back.
  • Ctrl + C with nothing selected cancels whatever is running or half-typed.

Copy and paste

In Windows Terminal, Ctrl + V pastes, and Ctrl + C copies when text is selected. Right-click also pastes.

In the Windows 10 PowerShell window, Ctrl + V pastes and so does a right-click. To copy, select text with the mouse and press Enter or Ctrl + C. Windows Terminal behaves more like other apps, another reason to install it.

Careful

Pasting several lines runs all of them, one after another. And never paste commands from a random website unless you understand what they do. Anything that downloads and runs a script in one go deserves extra suspicion.

Reading error messages

Red text is not a disaster. It is the terminal telling you what went wrong, usually in the first line. The two you will meet most:

git : The term 'git' is not recognized as the name of a cmdlet, function, script file, or operable program.

Meaning: PowerShell cannot find a program with that name. Either a typo, or the program is not installed, or it was installed after this terminal window was opened (close it and open a new one).

cd : Cannot find path 'C:\Users\you\Docs' because it does not exist.

Meaning: no folder with that name here. Check the spelling, check where you are with pwd, list what is here with ls, and let Tab type names for you.

Names with spaces

A space separates words in a command, so a folder like Program Files must be wrapped in quotes: cd 'C:\Program Files'. Easiest habit: never put spaces in names of project folders and files. Use dashes: my-site.

The prompt says PS C:\Users\you\Downloads>. What does cd .. do?

  • Goes to C:\
  • Goes to C:\Users\you
  • Deletes the Downloads folder

.. is the folder one level up. From Downloads, that is your home folder.

You installed a program, but the terminal says its name "is not recognized". What do you try first?

  • Reinstall Windows
  • Close the terminal and open a new one
  • Type the command in capital letters

A terminal only learns about new programs when it starts. Open a fresh window.

Fastest way to open a terminal already inside a project folder?

  • From File Explorer: right-click the folder background (Windows 11) or Shift + right-click (Windows 10), or type powershell in the address bar
  • Open PowerShell and use cd with the full path every time
  • Double-click the folder

Starting in the right folder saves typing and mistakes. The address bar trick works on both versions.
