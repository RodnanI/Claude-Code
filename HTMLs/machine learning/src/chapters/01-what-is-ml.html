What machine learning is

Machine learning is getting a computer to improve at a task by finding patterns in examples, instead of following rules a person wrote by hand.

Start by doing it. The figure below holds a tiny model. Each dot is an example with a known answer: class A or class B. The shaded background is the model's opinion about every other location on the plane. Add a few points and watch that opinion change.

That is the whole trick in miniature. You supplied data with answers, and the program produced behavior you never spelled out. The rest of this guide is about doing that well: with better models, on messier data, while measuring honestly how good the result is.

Rules versus learning

In traditional programming a person writes the rules and the computer applies them. In machine learning you flip it: you provide inputs together with the answers you want, and a training algorithm produces the rules. Those learned rules are called the model.

Why bother? Because for many useful tasks nobody can write the rules. Try writing an explicit rule for "this photo contains a cat" or "this email is a phishing attempt" or "this sentence is sarcastic". Humans do these effortlessly and cannot explain how. We can, however, collect thousands of labeled examples. ML turns examples into working behavior.

The four ingredients

Every supervised learning system, from a two-parameter line fit to a trillion-parameter language model, is built from the same four parts. Keep this table in your head; later chapters mostly swap one row at a time.

IngredientWhat it isExample for house prices
DataExamples: inputs (features) paired with known answers (labels).10,000 past sales: size, rooms, location, and the sale price.
ModelA function with adjustable numbers called parameters or weights.price = w1·size + w2·rooms + b
LossA single number measuring how wrong the model is on the data.Average squared difference between predicted and actual price.
OptimizerA procedure that changes the parameters to reduce the loss.Gradient descent: repeatedly nudge each weight downhill.

Kinds of learning

Supervised

Learn from answers

Every example has a label. Predict a number (regression: price, temperature) or a category (classification: spam or not, which digit). The bulk of industry ML.

Unsupervised

Find structure

No labels. Group similar customers (clustering), compress many features into a few (dimensionality reduction), spot oddballs (anomaly detection).

Self-supervised

Make your own labels

Hide part of the data and predict it from the rest, like predicting the next word in a sentence. This is how large language models are pretrained on raw text.

Reinforcement

Learn from reward

An agent acts in an environment and receives rewards. No one gives the right action, only a score. Used for games, robotics and fine-tuning chat models.

Words you will see everywhere

Example / sample / rowOne data point, such as one house or one email.
Feature / input / xA measurable property of an example: square meters, word counts, pixel values.
Label / target / yThe answer we want to predict for an example.
Parameters / weightsThe numbers inside the model that training adjusts.
HyperparametersSettings you choose before training: learning rate, tree depth, number of neighbors. Not learned from the training data directly.
TrainingFitting parameters to data by minimizing the loss.
GeneralizationPerforming well on new data the model has never seen. This is the real goal, and it is what makes ML hard.

Doing well on the training examples is easy: a lookup table can memorize them. The entire discipline exists to answer one question: will it work on data it has not seen yet? You will meet this question in almost every chapter.

AI, ML, deep learning, LLMs

Deep learning dominates images, audio and text. For tabular business data (spreadsheets and database tables) older methods such as gradient-boosted trees still frequently win. A good practitioner knows both worlds.

When not to use ML

  • A simple rule works. If ten lines of if statements solve it reliably, ship those.
  • You have no data and no realistic way to get it. Models are made of data.
  • Every error is unacceptable. ML is statistical: it will be wrong some fraction of the time. Plan for that or do not use it.
  • The world keeps changing faster than you can collect examples. A model only knows the past it was trained on.
