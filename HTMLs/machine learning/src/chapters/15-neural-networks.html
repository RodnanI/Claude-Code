Neural networks and backpropagation

Stack many simple units, each a weighted sum followed by a bend, and train them all at once with the chain rule. That is the entire foundation of deep learning.

The artificial neuron

You have already met the neuron: it is logistic regression. It takes inputs, multiplies each by a weight, adds a bias, and passes the result through an activation function:

a = f(w1x1 + w2x2 + … + wnxn + b) = f(w · x + b)

Why the bend matters

Without an activation function, a neuron is linear, and stacking linear layers gives... another linear function. Ten layers of matrix multiplications collapse into a single matrix. The non-linear activation is what lets depth add expressive power: each layer can fold and bend the space that the next layer sees.

Layers

A layer is many neurons reading the same inputs, each with its own weights. In matrix form a whole layer is one line, which is why GPUs are so good at this:

h = f(W x + b)W holds one row of weights per neuron. The output h is a new vector: the input re-described by learned features.

A multilayer perceptron (MLP) chains layers: input, one or more hidden layers, and an output layer. The output uses a sigmoid for binary classification, a softmax for multiple classes, or nothing (identity) for regression. The hidden layers learn their own features, the thing you did by hand with x² in chapter 06.

A network with a single hidden layer and enough neurons can approximate any reasonable continuous function as closely as you like. The theorem guarantees the capacity exists; it says nothing about how many neurons, how much data, or whether training will find the weights. In practice, depth (many layers) reaches the same power far more efficiently than width.

Backpropagation

Training needs the gradient of the loss with respect to every weight, possibly billions of them. Backpropagation computes all of them in one backward sweep, at about the cost of one forward pass. It is nothing but the chain rule applied systematically:

  1. Forward pass: compute and remember every intermediate value, from input to loss.
  2. Backward pass: start at the loss with gradient 1. At each operation, multiply the gradient arriving from above by the operation's local derivative and pass it down to its inputs.
  3. Update: every parameter now knows its gradient; take an optimizer step.

Frameworks like PyTorch and JAX build this graph automatically as your code runs (automatic differentiation), so you never derive gradients by hand. Understanding the mechanics still matters: it explains vanishing and exploding gradients, why some operations break training, and what loss.backward() actually does.

In code

import torch
from torch import nn

model = nn.Sequential(
    nn.Linear(2, 16), nn.ReLU(),        # hidden layer 1: h = relu(W1 x + b1)
    nn.Linear(16, 16), nn.ReLU(),       # hidden layer 2
    nn.Linear(16, 1),                   # output logit
)
loss_fn = nn.BCEWithLogitsLoss()        # sigmoid + log loss, numerically stable
opt = torch.optim.Adam(model.parameters(), lr=0.01)

    opt.zero_grad()
    loss.backward()                      # backpropagation fills .grad on every weight
    opt.step()                           # gradient descent update

What happens if you stack many layers with no activation functions?

A product of matrices is still a matrix. Without non-linearity, depth adds no expressive power.

In backpropagation, what does a multiplication node z = w · x pass back to w?

∂z/∂w = x, so by the chain rule w receives (upstream gradient) × x. Each input gets the other input as its local derivative.

Why did ReLU largely replace sigmoid in hidden layers?

Sigmoid's derivative is at most 0.25, so gradients shrink exponentially through many layers. ReLU passes gradient 1 for positive inputs and is also cheaper to compute.
