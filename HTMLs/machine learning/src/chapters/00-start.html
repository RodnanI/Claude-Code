Who this is for

You are curious about machine learning, maybe with an eye on working in it, and you want a real mental model instead of buzzwords. You do not need a math degree. You need to be comfortable with the idea of a function, a graph, and a little algebra. Where more math helps, it is introduced right when you need it, with a picture next to it.

How to read it

  1. Go in order the first time. Each chapter leans on the one before. Later you can jump around using the chapter list.
  2. Play with every figure before reading its caption. Form a guess about what a slider does, then test it. Prediction followed by feedback is literally how models learn, and it works on people too.
  3. Answer the questions at the end of each chapter. They are short and they tell you whether the idea actually landed.
  4. Type out the code. Every algorithm comes with a short Python snippet using the libraries people use at work: NumPy, scikit-learn and PyTorch. Run them in a free notebook such as Google Colab.
  5. Mark chapters complete with the button at the end of each one. Your progress is saved in this browser.

Almost every method in this guide is the same four-part recipe: data, a model with adjustable numbers, a loss that scores how wrong the model is, and an optimizer that nudges the numbers to make the loss smaller. When a new technique looks intimidating, ask which of the four parts it changes.
