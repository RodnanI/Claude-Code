Linear regression

The "hello world" of machine learning, and still one of the most used models in industry. Everything you learn here carries straight into neural networks.

The model

We want to predict a number y (a house price) from a feature x (its size). The simplest guess is a straight line:

ŷ = w x + bw is the slope (price per extra square meter), b is the intercept (the baseline). These two numbers are the model's parameters.

With several features the line becomes a flat plane (or hyperplane), but the idea is identical: each feature gets its own weight and the prediction is a weighted sum, which is a dot product.

ŷ = w1x1 + w2x2 + … + wnxn + b = w · x + b

The loss: how wrong is a line?

For each example, the residual is the gap between truth and prediction: yi − ŷi. We need one number summarizing all residuals. The standard choice squares each one and averages them, the mean squared error:

MSE = 1n Σi (yi − ŷi)²

Squaring does useful things: negatives cannot cancel positives, big misses are punished much more than small ones, and the result is a smooth bowl-shaped function of w and b that is easy to minimize. In the figure the squared errors are drawn as literal squares. Training means making their total area as small as possible.

You just did what every training algorithm does: adjust parameters, watch the loss, repeat. The only difference is that computers do it with calculus instead of sliders, and with millions of parameters instead of two.

Solving it exactly

For linear regression with MSE there is a closed-form answer, the normal equation. Put all examples in a matrix X (with a column of ones for the intercept) and targets in y:

θ* = (XTX)−1 XT y

This works well for thousands of features. For millions of rows or features, or for models without a closed form (almost all others), we use the iterative method in the next chapter: gradient descent.

Reading the weights

A weight says how much the prediction changes when its feature increases by one unit, holding all other features fixed. That makes linear models wonderfully interpretable, with caveats:

  • Weights are only comparable if features share a scale. Standardize first if you want to rank feature importance by weight size.
  • If two features are strongly correlated (size in m² and in ft²), their weights become unstable and can take absurd opposite signs. This is multicollinearity.
  • A weight measures association in this dataset, not causation. Houses with pools cost more, but adding a pool does not add the whole difference.

Curves with a linear model

"Linear" refers to the parameters, not the shape. Add features like x², x³ or log x and the same machinery fits curves. This is polynomial regression, and it is also the perfect way to learn about overfitting, which is exactly what chapter 08 does.

Measuring regression quality

MetricFormula ideaWhen to use
MAEmean of |error|Easy to explain ("off by $18k on average"); robust to outliers.
MSEmean of error²The usual training loss; punishes large errors hard.
RMSE√MSELike MSE but back in the target's units.
R²1 − MSE / variance of yFraction of variance explained. 1 is perfect, 0 is no better than always predicting the mean, negative is worse than that.
  • Extrapolation: a line fitted on 50 to 150 m² homes knows nothing about 900 m² mansions. It will still happily answer.
  • Outliers: MSE is sensitive to them, as the figure showed. Consider MAE or Huber loss if bad points are common.
  • Non-linear reality: always plot residuals. A pattern in them means the model is missing structure.

In code

import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_absolute_error, r2_score

X = np.array([[50], [70], [85], [100], [120]])     # size in m2
y = np.array([210, 265, 300, 350, 410])            # price in $1000s

model = LinearRegression().fit(X, y)
print(model.coef_, model.intercept_)               # slope w and intercept b
print(model.predict([[90]]))                       # price for a 90 m2 home

# The same fit via the normal equation
Xb = np.c_[np.ones(len(X)), X]                     # add a column of ones for b
theta = np.linalg.solve(Xb.T @ Xb, Xb.T @ y)        # [b, w]

Why is the error squared in MSE rather than just summed?

Summing raw residuals lets +10 and -10 cancel to zero. Squaring keeps everything positive and gives a smooth loss that heavily penalizes big misses.

A model has R² = 0 on the test set. What does that mean?

R² compares your error to the error of the constant "predict the mean" baseline. Zero means no improvement over that baseline.
