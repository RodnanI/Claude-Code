Convolutional neural networks

How machines learned to see: slide small learned filters across an image, detect edges, then shapes, then objects.

Images are grids of numbers

A grayscale image is a matrix of brightness values. A color image is three of them stacked (red, green, blue channels). A modest 224×224 color photo is 150,528 numbers. Feeding that into a regular fully connected layer with 1,000 neurons needs 150 million weights for the first layer alone, and the network would have to learn "a cat in the top left" and "a cat in the bottom right" as unrelated facts.

Convolutional networks fix both problems with two ideas that match how images work:

  • Local connectivity: nearby pixels matter together. Each unit looks only at a small patch.
  • Weight sharing: an edge is an edge wherever it appears. The same small filter is reused at every position.

Convolution

A kernel (or filter) is a small grid of weights, typically 3×3. Place it over a patch of the image, multiply overlapping numbers, and sum them: one output value. Slide it one step and repeat. The grid of outputs is a feature map: a picture of where the pattern the kernel encodes appears.

The building blocks

PieceWhat it does
ChannelsA conv layer has many kernels (say 64), each producing its own feature map. The next layer's kernels read all 64 maps at once, combining features.
PaddingAdds a border of zeros so the output keeps the input's size (the figure uses this).
StrideHow far the kernel moves each step. Stride 2 halves the resolution.
PoolingSummarizes small blocks, usually by their maximum. Shrinks the map and makes detection robust to small shifts.
Receptive fieldThe patch of the original image a unit can see. It grows with every layer, so deep units respond to large structures.

A short history worth knowing

YearModelWhy it mattered
1998LeNet-5Read handwritten digits on bank checks. The template for every CNN since.
2012AlexNetCrushed the ImageNet competition using GPUs and ReLU. The start of the deep learning boom.
2015ResNetSkip connections (add a layer's input to its output) made 100+ layer networks trainable. Now used almost everywhere, including transformers.
2020Vision TransformerChopped images into patches and applied transformers (next chapter). Competitive with CNNs at scale.

You almost never train an image model from scratch at work. Take a network pretrained on millions of images, keep its feature-extracting layers, replace the final layer with one for your classes, and fine-tune. A few hundred labeled images per class can then give excellent results. The same pattern (pretrain big, fine-tune small) dominates text and audio too.

Beyond classification, the same building blocks power object detection (boxes around every object, as in the YOLO family), segmentation (a label for every pixel, as in U-Net for medical images) and the denoising networks inside diffusion image generators.

In code

import torch
from torch import nn
import torchvision

class SmallCNN(nn.Module):
    def __init__(self, n_classes=10):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(1, 32, kernel_size=3, padding=1), nn.ReLU(), nn.MaxPool2d(2),   # 28x28 -> 14x14
            nn.Conv2d(32, 64, kernel_size=3, padding=1), nn.ReLU(), nn.MaxPool2d(2),  # 14x14 -> 7x7
        )
        self.head = nn.Sequential(nn.Flatten(), nn.Linear(64 * 7 * 7, 128), nn.ReLU(),
                                  nn.Linear(128, n_classes))
    def forward(self, x):
        return self.head(self.features(x))

# Transfer learning: reuse a pretrained ResNet, retrain only the last layer
net = torchvision.models.resnet18(weights="IMAGENET1K_V1")
for p in net.parameters():
    p.requires_grad = False
net.fc = nn.Linear(net.fc.in_features, 5)   # 5 new classes; only this layer trains

Why do CNNs need far fewer parameters than fully connected networks on images?

Weight sharing: one 3×3 kernel has 9 weights no matter how large the image, and it detects its pattern anywhere.

What does 2×2 max pooling do to a 32×32 feature map?

Each non-overlapping 2×2 block is replaced by its maximum, halving width and height.

You have 800 labeled photos of 4 product types. What is the most sensible approach?

Pretrained features already capture edges, textures and shapes. Fine-tuning adapts them to your classes with little data.
