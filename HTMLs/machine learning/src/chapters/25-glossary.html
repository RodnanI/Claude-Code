Glossary

Every term from the guide, in plain language. Type to filter.

Accuracy
Share of predictions that are correct. Misleading when classes are imbalanced.
Activation function
The non-linear function applied after a neuron's weighted sum (ReLU, tanh, sigmoid, GELU). Without it, deep networks collapse to linear models.
Adam
An optimizer combining momentum with per-parameter adaptive step sizes. The default for deep learning; AdamW adds decoupled weight decay.
Agent
In reinforcement learning, the decision maker. In LLM applications, a model that calls tools and acts in a loop.
Attention
A mechanism where each token computes weights over all other tokens (query-key dot products plus softmax) and mixes their values accordingly.
AUC (ROC AUC)
Area under the ROC curve: the probability that a random positive is scored higher than a random negative. 0.5 is random, 1.0 perfect.
Autoencoder
A network trained to reconstruct its input through a narrow bottleneck, learning a compressed representation.
Backpropagation
Computing gradients of the loss with respect to all weights by applying the chain rule backward through the network.
Bagging
Bootstrap aggregating: train models on random resamples of the data and average them. The basis of random forests.
Baseline
A simple reference solution (predict the mean, majority class, last value) that any real model must beat.
Batch normalization
Normalizing a layer's outputs over the mini-batch to stabilize and speed up training.
Batch size
Number of examples used to estimate the gradient for one update.
Bias (model)
Systematic error from overly simple assumptions; high bias means underfitting. Also the intercept term b in a linear model or neuron.
Bias (fairness)
Systematically worse or unfair outcomes for some groups, often inherited from data.
Boosting
Building an ensemble sequentially, each model correcting the errors of the previous ones. Gradient boosting fits each new tree to residuals.
Calibration
Whether predicted probabilities match observed frequencies: of cases given 70%, about 70% should be positive.
Chain rule
The derivative of nested functions is the product of their derivatives. The math behind backpropagation.
Class imbalance
When one class is much rarer than others. Calls for suitable metrics, class weights or resampling.
Classification
Supervised learning that predicts a category.
Clustering
Grouping similar examples without labels (k-means, DBSCAN, hierarchical).
CNN
Convolutional neural network: uses small shared kernels slid across the input. The classic architecture for images.
Concept drift
A change over time in the relationship between inputs and target, which degrades deployed models.
Confusion matrix
A table of true positives, false positives, false negatives and true negatives.
Context window
The maximum number of tokens an LLM can consider at once.
Convolution
Sliding a small kernel over an input, computing a weighted sum at each position to produce a feature map.
Cosine similarity
The cosine of the angle between two vectors; compares direction regardless of length. Standard for embeddings.
Cross-entropy
The loss for classification: the negative log of the probability assigned to the true class.
Cross-validation
Splitting training data into k folds and rotating which fold is used for validation, giving a more reliable estimate.
Curse of dimensionality
As features multiply, data becomes sparse and distances lose meaning, hurting many methods.
Data augmentation
Creating extra training examples by transforming existing ones (flips, crops, noise).
Data leakage
Information unavailable at prediction time sneaking into training, producing falsely good validation scores.
DBSCAN
Density-based clustering that finds arbitrarily shaped clusters and marks sparse points as noise.
Decision boundary
The surface where a classifier switches from one class to another.
Decision tree
A model that predicts by following a sequence of feature threshold questions to a leaf.
Deep learning
Machine learning with neural networks of many layers.
Derivative
The rate of change of a function; the slope of its tangent line.
Diffusion model
A generative model that learns to reverse a gradual noising process, used for image generation.
Dimensionality reduction
Representing data with fewer features while keeping as much structure as possible (PCA, UMAP).
Dot product
Sum of products of matching vector entries. Measures alignment; the core operation of linear models and neurons.
Dropout
Randomly disabling neurons during training so the network cannot rely on any single one; a regularizer.
Early stopping
Stopping training when validation performance stops improving.
Embedding
A learned vector representing an item (word, product, user) so that similar items are close.
Ensemble
Combining several models to get better, more stable predictions.
Epoch
One full pass over the training data.
Epsilon-greedy
Exploration strategy: random action with probability ε, best-known action otherwise.
Evaluation set (eval)
A fixed collection of inputs with expected outputs used to measure a model or prompt, especially for LLM applications.
F1 score
Harmonic mean of precision and recall.
Feature
An input variable describing an example.
Feature engineering
Creating informative features from raw data using domain knowledge.
Fine-tuning
Continuing to train a pretrained model on a smaller, task-specific dataset.
Foundation model
A large model pretrained on broad data that can be adapted to many tasks (LLMs, vision-language models).
Generalization
Performing well on new, unseen data. The real goal of ML.
Gini impurity
A measure of how mixed the classes in a node are; trees choose splits that reduce it.
Gradient
The vector of partial derivatives; points in the direction of steepest increase.
Gradient descent
Iteratively moving parameters against the gradient to reduce the loss.
Hallucination
A fluent but false output from a generative model.
Hyperparameter
A setting chosen before training (learning rate, depth, k), tuned on validation data.
Inference
Using a trained model to make predictions.
k-means
Clustering by alternately assigning points to the nearest of k centers and moving centers to their points' mean.
k-nearest neighbors
Predicting from the labels of the k most similar training examples.
Kernel (SVM)
A function computing dot products in an implicit high-dimensional feature space, enabling non-linear boundaries.
Kernel (CNN)
A small grid of learned weights slid across an image; also called a filter.
L1 / L2 regularization
Penalties on the absolute (L1, lasso) or squared (L2, ridge, weight decay) size of weights. L1 produces sparse models.
Label
The known answer for a training example; the target.
Large language model (LLM)
A very large transformer trained on next-token prediction over huge text corpora, then tuned to follow instructions.
Learning rate
The step size in gradient descent; the most important training hyperparameter.
Linear regression
Predicting a number as a weighted sum of features, fit by minimizing squared error.
Log loss
Binary cross-entropy; penalizes confident wrong probabilities heavily.
Logistic regression
A linear model passed through a sigmoid to output a class probability.
LoRA
Low-rank adaptation: fine-tuning by training small added matrices instead of all weights.
Loss function
A number measuring how wrong the model is; training minimizes it.
MAE / MSE / RMSE
Mean absolute error, mean squared error, and its square root: standard regression metrics.
Mini-batch
A small random subset of training data used for one gradient step.
MLOps
Practices and tools for deploying, monitoring and maintaining ML systems in production.
Momentum
An optimizer technique that accumulates past gradients as velocity to speed up and smooth descent.
Naive Bayes
A probabilistic classifier using Bayes' rule with the assumption that features are independent given the class.
Neural network
Layers of neurons, each a weighted sum followed by an activation, trained with backpropagation.
One-hot encoding
Representing a category as a vector of 0s with a single 1.
Overfitting
Fitting training data, including its noise, so closely that performance on new data suffers.
Parameter
A number inside the model learned during training (a weight or bias).
PCA
Principal component analysis: projecting data onto the directions of greatest variance.
Pipeline
A chained sequence of preprocessing and modeling steps fit and applied together, preventing leakage and skew.
Policy
In reinforcement learning, the rule mapping states to actions.
Pooling
Downsampling a feature map by summarizing blocks, usually with their maximum.
Precision
Of the items predicted positive, the share that truly are.
Pretraining
Training a large model on broad data with a generic objective before adapting it.
Prompt injection
An attack where instructions hidden in content an LLM reads hijack its behavior.
Q-learning
A reinforcement learning algorithm that learns the expected return of each action in each state.
R²
Fraction of target variance explained by a regression model.
RAG
Retrieval-augmented generation: retrieving relevant documents and adding them to an LLM's prompt.
Random forest
An ensemble of decision trees trained on bootstrap samples with random feature subsets, averaged.
Recall
Of the truly positive items, the share the model caught. Also called sensitivity or true positive rate.
Regression
Supervised learning that predicts a number.
Regularization
Any technique that discourages overly complex models to improve generalization.
Reinforcement learning
Learning to act by trial and error from rewards.
ReLU
Rectified linear unit, max(0, z). The most common hidden-layer activation.
Residual (connection)
Adding a layer's input to its output so gradients flow through very deep networks. Also: a prediction error, y minus y hat.
RLHF
Reinforcement learning from human feedback: tuning a model toward responses people prefer.
ROC curve
True positive rate plotted against false positive rate across all thresholds.
SHAP
A method that attributes each prediction to feature contributions, based on Shapley values.
Sigmoid
The S-shaped function 1 / (1 + e-z) mapping any number into (0, 1).
Softmax
Turns a vector of scores into probabilities that sum to 1.
Standardization
Rescaling a feature to mean 0 and standard deviation 1.
Supervised learning
Learning from examples paired with correct answers.
Support vector machine
A classifier that finds the maximum-margin boundary, determined by the support vectors.
Temperature
A sampling setting that sharpens (low) or flattens (high) a model's output distribution.
Test set
Held-out data used once at the end to estimate real-world performance.
Token
A unit of text (word or word piece) that language models read and produce.
Top-k / top-p sampling
Restricting sampling to the k most likely tokens, or to the smallest set whose probabilities sum to p.
Transfer learning
Reusing a model trained on one task as the starting point for another.
Transformer
A neural architecture built from self-attention and feed-forward blocks; the basis of modern LLMs.
Underfitting
A model too simple to capture the real pattern; high error on training and test data alike.
Unsupervised learning
Finding structure in data without labels.
Validation set
Data held out from training and used to compare models and tune hyperparameters.
Vanishing gradient
Gradients shrinking toward zero through many layers, stalling learning in early layers.
Variance (model)
Sensitivity to the particular training sample; high variance means overfitting.
Vector database
A system storing embeddings and answering nearest-neighbor queries quickly, used for semantic search and RAG.
Weight decay
L2 regularization applied during optimization, shrinking weights a little at every step.
