Logistic regression

Despite the name, it is a classifier. It predicts the probability that an example belongs to a class, and it is the direct ancestor of the neuron.

Suppose we want to predict pass or fail from hours studied. Labels are 0 (fail) and 1 (pass). We could fit a straight line, but a line shoots below 0 and above 1, which makes no sense as a probability, and a few extreme students would tilt it badly. We want an S-shaped curve that stays between 0 and 1.

The sigmoid

Logistic regression computes the same weighted sum as linear regression, then squashes it through the sigmoid function:

σ(z) = 11 + e−z     p = σ(w · x + b)Large positive z gives p near 1, large negative z gives p near 0, and z = 0 gives exactly 0.5.

Log loss: punishing confident mistakes

For classification we do not use squared error. We use log loss, also called binary cross-entropy:

L = −1n Σi [ yi log pi + (1 − yi) log(1 − pi) ]

It reads more simply than it looks: for each example, take the probability the model gave to the correct answer, and add −log of it. Predicting 0.9 for the truth costs 0.1. Predicting 0.5 costs 0.69. Predicting 0.01 for the truth costs 4.6. Being confidently wrong is catastrophically expensive, which is exactly the pressure we want.

Combined with a sigmoid, squared error gives a bumpy, non-convex loss with tiny gradients when the model is confidently wrong, the moment it most needs to learn. Log loss gives a convex bowl and a gradient that is beautifully simple: ∂L/∂z = p − y, prediction minus truth.

Boundaries in two dimensions

With two features the decision boundary w1x1 + w2x2 + b = 0 is a straight line. Logistic regression is a linear classifier. That is a strength (simple, fast, stable, interpretable) and a limitation, as the figure shows.

Feature engineering can turn a linear model into a non-linear one. Neural networks take this to its conclusion: instead of you inventing x² and xy, hidden layers learn which features to build.

More than two classes: softmax

For K classes (cat, dog, bird), compute one score per class, zk = wk · x + bk, then turn scores into probabilities that sum to one with the softmax:

pk = ezkΣj ezj

The loss becomes cross-entropy: −log of the probability assigned to the true class. Softmax plus cross-entropy is the output layer of practically every classification network, including the one inside a language model choosing the next word from 100,000 candidates.

Reading the model

Each weight shifts the log-odds log(p / (1 − p)). So ew is an odds ratio: a weight of 0.7 on "hours studied" means each extra hour multiplies the odds of passing by e0.7 ≈ 2. This interpretability is why logistic regression is still standard in medicine, credit scoring and anywhere decisions must be explained.

In code

from sklearn.linear_model import LogisticRegression
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import make_pipeline

clf = make_pipeline(StandardScaler(), LogisticRegression(C=1.0))
clf.fit(X_train, y_train)

proba = clf.predict_proba(X_test)[:, 1]    # P(class 1) for each example
pred = (proba >= 0.5).astype(int)          # the default threshold
print(clf.score(X_test, y_test))           # accuracy
# C is the inverse regularization strength: smaller C = simpler model

Logistic regression outputs 0.97 for an example whose true label is 0. How does log loss treat this?

The probability of the true class was 0.03, and −log(0.03) ≈ 3.5, much larger than the 0.67 for predicting 0.51.

What shape is the decision boundary of plain logistic regression on two raw features?

The boundary is where w·x + b = 0, which is a line in 2D and a flat hyperplane in higher dimensions. Curves require engineered features or a different model.

Softmax scores are [3, 3, 3] for three classes. What are the probabilities?

Equal scores mean equal exponentials, so each class gets exactly one third. Softmax only cares about differences between scores.
