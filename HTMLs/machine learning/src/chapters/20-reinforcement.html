Reinforcement learning

No labeled answers, only consequences. An agent tries things, collects rewards and penalties, and gradually learns which actions pay off in the long run.

The loop

At each step the agent observes a state, picks an action according to its policy, and the environment responds with a new state and a numeric reward. The goal is to maximize the total reward over time, called the return. Rewards can be delayed: a chess move's value may only show twenty moves later. Working out which earlier actions deserve the credit is the core difficulty.

Future rewards are usually discounted by a factor γ between 0 and 1 per step:

G = r1 + γ r2 + γ² r3 + …γ near 1 means patient and far-sighted; γ near 0 means greedy for immediate reward.

Q-learning

One classic approach learns a table of Q-values: Q(s, a) estimates the return you get by taking action a in state s and acting well afterward. If you know Q, the best policy is simply "pick the action with the highest Q". After every step, nudge the estimate toward what just happened:

Q(s, a) ← Q(s, a) + α [ r + γ maxa′ Q(s′, a′) − Q(s, a) ]The bracket is the surprise: the reward received plus the best value of the next state, minus what we expected.

Notice the estimate is built from another estimate, Q(s′, a′). Value information flows backward from the goal, one step at a time, episode by episode.

Explore or exploit?

An agent that always takes the best-known action never discovers better ones. An agent that always explores never cashes in. The simple ε-greedy rule takes a random action with probability ε and the best-known action otherwise, often lowering ε over time. The same dilemma appears in A/B testing and recommendation systems, where it is studied as the multi-armed bandit problem.

Deep reinforcement learning

A table works for 48 grid cells, not for the pixels of a video game or the joint angles of a robot. Deep RL replaces the table with a neural network:

  • DQN (2015): a CNN estimates Q-values from raw screen pixels. It learned dozens of Atari games from score alone.
  • Policy gradient methods train the policy network directly to make high-return actions more likely. PPO is the workhorse, including in RLHF for language models (chapter 19).
  • AlphaGo and AlphaZero combined deep networks, search and self-play to beat world champions at Go and chess.
  • Sample hungry: millions of trials are cheap in a simulator and impossible on real hardware.
  • Reward hacking: agents optimize the reward you wrote, not the one you meant. A famous boat-racing agent learned to spin in circles collecting points instead of finishing the race.
  • Unstable training and high variance between runs; results depend heavily on random seeds.

For most business problems supervised learning is the better tool. Use RL when decisions affect future data and there is a simulator or a safe way to experiment.

In code

import numpy as np
import gymnasium as gym

env = gym.make("FrozenLake-v1", is_slippery=False)
Q = np.zeros((env.observation_space.n, env.action_space.n))
alpha, gamma, eps = 0.5, 0.95, 0.2

for episode in range(2000):
    s, _ = env.reset()
    done = False
    while not done:
        a = env.action_space.sample() if np.random.rand() < eps else int(np.argmax(Q[s]))
        s2, r, terminated, truncated, _ = env.step(a)
        target = r + (0 if terminated else gamma * Q[s2].max())
        Q[s, a] += alpha * (target - Q[s, a])       # the Q-learning update
        s, done = s2, terminated or truncated
print(np.argmax(Q, axis=1).reshape(4, 4))           # learned policy

What does the discount factor γ control?

γ weights rewards k steps ahead by γk. Higher values make the agent value long-term outcomes.

An agent always takes the action it currently believes is best, from its very first episode. What is the risk?

Pure exploitation locks in early, possibly poor, habits. Some exploration is needed to find better strategies.
