Forks and open source

You can read any public repository, but you cannot push to other people's projects. To contribute anyway, you fork: make your own copy on GitHub, change that, and send a pull request back to the original.

Fork, clone, branch: not the same thing

WordMakes a copy whereUse it when
BranchInside the same repositoryYou can push there and want to work on something separately
CloneOn your computerYou want to work on any repository locally
ForkOn GitHub, under your accountYou want to change a project you cannot push to

How the pieces connect

  1. Fork: click Fork on the project's GitHub page. You now own you/cookbook.
  2. Clone your fork: git clone https://github.com/you/cookbook.git. Your fork becomes origin.
  3. Branch and commit as usual.
  4. Push to your fork: git push -u origin my-fix.
  5. Open a pull request: GitHub offers to open it against the original project, and its maintainers review it like any other PR.

Staying in sync with the original

While you work, the original project moves on, and your fork does not update itself. Add the original as a second remote, traditionally called upstream, and bring its changes in:

$ git remote add upstream https://github.com/open-kitchen/cookbook.git
$ git fetch upstream
$ git switch main
$ git merge upstream/main
$ git push origin main

Or click Sync fork on your fork's GitHub page, then git pull locally. Same result.

Contributing without embarrassment

  • Read CONTRIBUTING.md first. Most projects explain their rules, style and how to run the tests.
  • Look for issues labeled good first issue or help wanted. They are picked for newcomers.
  • Comment on the issue before big work, so two people do not solve the same thing.
  • Keep the pull request focused on one thing. Do not reformat the whole project on the way.
  • Be patient. Maintainers are often volunteers. A polite nudge after a week is fine.
  • Documentation fixes count. Clarifying a confusing README is a perfect first contribution.

You forked a project and cloned your fork. What is origin?

Right. origin is wherever you cloned from. The original project is the one you add as upstream.
