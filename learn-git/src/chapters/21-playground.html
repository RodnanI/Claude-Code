Final challenge

One last mission that strings everything together in the order it happens in real life. After that, a sandbox with no rules, and pointers for where to go next.

The graduation mission

Sam started a shared cookbook on GitHub and gave you access. You will clone it, change the menu and push. Except Sam is editing the very same line at the very same time. You will need clone, commit, push, pull, conflict resolution and push again.

Sandbox

Anything goes. Two GitHub repositories exist here: an empty one at https://github.com/you/sandbox.git, and Sam's cookbook to clone. Type help for the command list, sim teammate to make a teammate push, and borrow ideas from the cheat sheet.

Things to try in the sandbox

  • Create a project and push it to the empty sandbox repository with git remote add and git push -u.
  • Make several branches, merge them in different orders, and watch the map.
  • Cause a conflict on purpose. Back out with git merge --abort the first time, then resolve it properly.
  • Rebase a branch, then find the old commits with git reflog.
  • Delete the .git folder with rm -rf .git and see what is left. Only in here, please.

Where to go from here

  • Use it for real. Put your next project, your notes or your config files under git and push them to GitHub. Daily use is what makes it stick.
  • Contribute one small thing to an open source project. A typo fix in documentation is a perfectly respectable first pull request.
  • Read Pro Git, the free official book, when you want every detail.
  • GitHub Docs cover every button on the website.
  • When stuck: git status first, then the Undo stop.
