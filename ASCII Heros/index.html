ASCII Heroes / Vol. 1

Thirteen landing-page heroes drawn entirely in glyphs. Sharks, black holes, starlings and ink, all alive, all a single HTML file you can lift straight into a site.

  • 13 heroes
  • 0 dependencies
  • 2 themes each
  • 1 file each

How they work

Every hero renders into a canvas as a grid of characters. Cells are batched by brightness into row strings, so a full screen of glyphs costs a few hundred draw calls a frame.

Using one

Open a hero and press Download. You get one HTML file with the engine inlined: no build step, no fonts to load, no images. Swap the copy and ship it.

Themes

Each hero has its own dark and light treatment. The toggle here and inside every hero stay in sync, and the choice is remembered.
